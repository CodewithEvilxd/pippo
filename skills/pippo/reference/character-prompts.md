# Pippo character sprite prompts

Har character ke liye **do alag prompts** hain: ek DIRECTIONS image ke liye aur ek REACTIONS image ke liye. Dono prompts ko alag-alag paste karo. Pehle directions prompt chalao; phir usi ChatGPT chat mein reaction prompt paste karke bani hui directions image bhi reference ke roop mein attach karo. Isse reaction sheet mein wahi character aur style match hoga.

## Output notes

- Har folder mein do alag PNG files chahiye: `characters/<name>/directions.png` aur `characters/<name>/reactions.png`.
- Image tool mein transparent background option select karo. White/grey background ya checkerboard transparency nahi hota.
- Dono sheets square 3-by-3 grids hain; unhe ek 3-by-6 image mein combine mat karna.
- Gallery mein 57 purane sprite names hain; Pippo aur 7 inactive source folders ke prompts bhi neeche hain, kyunki sabhi 65 `characters/` folders inspect kiye gaye.
- `fox-ink`, `fox-paper`, `fox-pixel`, `fox-riso`, `fox-sketch` same fox ke style variants hain, alag species nahi.
